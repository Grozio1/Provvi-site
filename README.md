# Provvi — site

Marketing page for [provvi.app](https://provvi.app).

Served by GitHub Pages from `main` at the repository root. This repo exists
separately from the app source so that the app repository can be private while
the site stays public — GitHub Pages cannot serve from a private repository on
a free account.

- `index.html` — the page, self-contained (inline CSS and SVG, no build step)
- `CNAME` — custom domain binding for provvi.app

Privacy Policy and Terms of Service are served from their own repositories,
`Provvi-privacy` and `Provvi-tos`, and are linked from this page.
